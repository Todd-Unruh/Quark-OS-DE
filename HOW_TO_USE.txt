================================================================================
                    QUARK-OS-3 — COMPLETE USAGE GUIDE
================================================================================

Quark-OS-3 is a 32-bit hobby operating system with a bash-style shell and
built-in Forge_High language support. Write programs in .fg files and run them
directly from the command prompt.

--------------------------------------------------------------------------------
1. BUILDING QUARK-OS-3 (on your Linux host)
--------------------------------------------------------------------------------

Requirements:
  - gcc, nasm, ld (build-essential)
  - grub-mkrescue (grub-pc-bin) for ISO creation
  - qemu-system-i386 (optional, for testing)

Commands:
  cd Quark-OS-3
  make clean
  make              # builds quark_kernel.elf and quark_os_3.iso
  make run          # boot in QEMU

Verify multiboot:
  make check-multiboot

--------------------------------------------------------------------------------
2. INSTALLING TO A COMPUTER / USB DRIVE
--------------------------------------------------------------------------------

From the Quark-OS-3 shell, type:
  install

This shows install steps. On the host:

  sudo ./install.sh /dev/sdX

Replace /dev/sdX with your USB device (e.g. /dev/sdb). WARNING: this erases
the target device.

Alternative: burn quark_os_3.iso to a USB with dd:
  sudo dd if=quark_os_3.iso of=/dev/sdX bs=4M status=progress

Boot the PC from the USB drive (enable legacy/BIOS boot if needed).

--------------------------------------------------------------------------------
3. FORGE_High — RUNNING PROGRAMS
--------------------------------------------------------------------------------

Syntax:
  forge file.fg

Example (pre-installed):
  forge hello.fg

Create your own program:
  edit myprog.fg

Sample myprog.fg:
  print "My first Forge program on Quark-OS!"
  set n = 5
  repeat @n:
      print "Hello!"
  func double(x):
      return x + x
  set result = call double(21)
  print "double(21) = (@result)"

Supported Forge features:
  - print, set, const
  - if / else (indented blocks)
  - repeat N:, while, for (basic)
  - func / call / return
  - input "prompt" variable
  - @variable interpolation in strings
  - Basic arithmetic (+ - * /)

File locations:
  Programs live in the ramfs (in-memory filesystem). Use ls, edit, cat to manage
  .fg files in the current directory.

--------------------------------------------------------------------------------
4. MAKING DESKTOP APPS WITH FORGE
--------------------------------------------------------------------------------

Forge scripts can also be desktop apps. Create a .fg file with a window
declaration, a draw() function, and optional functions used by widgets:

  window "Counter" 360 220
  set count = 0

  func draw():
      panel 16 16 312 112 "#252a32"
      label 32 28 "Forge counter" "#ffffff"
      text 32 58 "Count: @count" "#d8e0ea"
      button 32 88 120 30 "Add one" increment
      checkbox 180 94 "Enabled" enabled toggle_enabled

  func increment():
      set count = count + 1

  func toggle_enabled():
      print "Enabled is now @enabled"

Drawing coordinates are relative to the window's content area:

  fill x y width height "#RRGGBB"       Filled rectangle
  rect x y width height "#RRGGBB"       Rectangle outline
  panel x y width height "#RRGGBB"      Rounded panel with themed border
  line x1 y1 x2 y2 "#RRGGBB"            Line
  circle center_x center_y radius "#RRGGBB"
  text x y "Text" "#RRGGBB"             Text (the color is optional)
  label x y "Text" "#RRGGBB"            Alias for text
  button x y width height "Text" action Clickable button
  checkbox x y "Text" variable action   Clickable checkbox

Checkboxes toggle their named Forge variable between 0 and 1, then call their
action function. Button and checkbox actions are Forge functions with no
parameters. Values and drawing commands in draw() are refreshed after clicks.

In the desktop Files app, select a .fg file and press G to run it. A file with
both a window declaration and draw() opens as a window; a regular Forge script
runs and displays its output. Double-clicking opens the file in the editor;
Forge files only run with G. Forge app windows use the normal title bar,
including close, minimize, maximize, and drag controls.

The Files app includes widgets.fg, a preloaded demo showing drawing commands,
text, buttons, and checkboxes. Select it and press G to try it.

--------------------------------------------------------------------------------
5. SHELL BASICS
--------------------------------------------------------------------------------

  help              List all commands
  help forge        Help for forge command
  ls                List files
  cd docs           Change directory
  cat hello.fg      View a file
  edit myfile.fg    Simple text editor (^C to save)
  clear             Clear screen
  version           Show Quark-OS version
  reboot / halt     Power control

Chain commands with semicolon:
  clear ; forge hello.fg

Redirect output:
  forge hello.fg > output.txt

--------------------------------------------------------------------------------
6. FORGE_LOW (KERNEL / BOOTLOADER — SEPARATE PROJECT)
--------------------------------------------------------------------------------

Forge_Low is the bare-metal sibling of Forge_High, located in ~/Forge_Low.
Use it to write bootloaders and kernel code:

  cd ~/Forge_Low
  make test
  make bootloader

Bootloader sources use # bit 32 or # bit 64 on line 1.

--------------------------------------------------------------------------------
7. TROUBLESHOOTING
--------------------------------------------------------------------------------

  forge: file not found     Use ls to check filename; files are per-directory
  Build fails               Ensure gcc-multilib and nasm are installed
  ISO not created           Install grub-pc-bin / grub2-common
  QEMU black screen         Try: qemu-system-i386 -cdrom quark_os_3.iso -serial stdio

--------------------------------------------------------------------------------
